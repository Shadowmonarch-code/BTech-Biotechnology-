## ✨ Overview

AgriPrep is a modern, fully-responsive web platform designed specifically for students preparing for **ICAR AIEEA** (All India Entrance Examination for Agriculture). Built with cutting-edge web technologies, it provides comprehensive study materials, test series, and expert lectures to help you achieve your dream rank.

---

## 🚀 Features

### 🔐 Authentication System
- **Secure Login/Signup** with form validation
- **Persistent Sessions** using LocalStorage
- **User Dashboard** with personalized greeting
- **Logout Functionality**

### 🎨 Modern UI/UX
- **Dark Mode Toggle** - Easy on the eyes for night study sessions
- **Fully Responsive Design** - Works seamlessly on Desktop, Tablet & Mobile
- **Smooth Animations** - Engaging user experience with hover effects and transitions
- **Professional Color Scheme** - Agriculture-themed green palette

### 📚 Comprehensive Resources
- **📜 Previous Year Questions (PYQ)** - 2018-2024 papers with solutions
- **📝 Sample Papers** - Subject-wise model test papers
- **💻 Online Test Series** - Full-length mocks, subject-wise & chapter-wise quizzes
- **🎥 Expert Lectures** - Video lectures covering complete syllabus

### 📊 Interactive Elements
- **Animated Statistics Counter** - Live count of students, lectures, and tests
- **Toast Notifications** - Real-time feedback for all actions
- **Dynamic Content Loading** - Resources loaded from mock database
- **Mobile Hamburger Menu** - Smooth navigation on small screens

## 🏃 Quick Start

### Option 1: Direct Open
Simply open `index.html` in any modern web browser:
```bash
# Navigate to project folder
cd icar-prep

# Open in default browser
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

### Option 2: Local Server (Recommended)
```bash
# Using Python 3
python3 -m http.server 8080

# Using Python 2
python -m SimpleHTTPServer 8080

# Using Node.js (if installed)
npx serve .
```

Then visit: **http://localhost:8080**

## 🎯 Key Functionalities

### Dark Mode
Click the moon/sun icon in the navigation bar to toggle between light and dark themes. Your preference is saved automatically.

### User Authentication
1. Click **Log In** or **Sign Up** button
2. Enter your credentials
3. Access protected resources
4. Session persists even after browser refresh

### Resource Access
- **Logged Out**: Clicking resources prompts login
- **Logged In**: Direct access with action feedback (Download/Watch/Start Test)
